# 發布檢查清單

## 前端

1. 檢查 JavaScript 語法：

```powershell
node --check 台股策略系統/web/app.js
```

2. 若修改 `web/app.js`，同步更新 `web/index.html` 的版本參數：

```html
<script src="app.js?v=YYYYMMDDHHmm"></script>
```

3. 發布後確認：

- 按鈕會從「更新中」回到「更新資料」。
- 總資產、現金、日期、候選股、持倉、交易紀錄都有畫面。
- Apps Script 失敗時會顯示備援資料，不會白屏。
- 交易簽名變動後，前端會立即刷新。

## GitHub Pages

公開網站讀 `gh-pages`，不是只讀 `main`。改前端後需同步兩個分支並實測公開網址。

## Apps Script

修改 `apps_script/Code.gs` 或 `appsscript.json` 後：

1. 用 clasp push。
2. 建立新版 deployment。
3. 若 scope 改變，重新授權。
4. 測試：

```text
.../exec?action=status
.../exec?action=settings
.../exec?action=read
```
